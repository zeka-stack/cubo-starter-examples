# 运维端点示例（Reactive）

基于 Spring WebFlux 的运维端点示例，展示 `cubo-endpoint-reactive-spring-boot-starter` 在响应式环境下的健康检查和指标暴露能力。

## 运行方式

```bash
mvn spring-boot:run
```

启动后访问端点页面：http://localhost:8080/actuator

## 演示特性

- 响应式环境下的健康检查端点
- 非阻塞的指标采集和暴露
- WebFlux 环境下的管理端点集成
