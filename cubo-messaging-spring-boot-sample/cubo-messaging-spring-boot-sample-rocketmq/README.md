# 消息中间件示例（RocketMQ）

基于 RocketMQ 的消息处理示例，展示 `cubo-messaging-rocketmq-spring-boot-starter` 的消息发送和消费能力。

## 运行方式

需要先启动 RocketMQ 服务，然后运行示例：

```bash
mvn spring-boot:run
```

## 演示特性

- RocketMQ 生产者和消费者配置
- 消息发送与接收
- 消息监听器注册
