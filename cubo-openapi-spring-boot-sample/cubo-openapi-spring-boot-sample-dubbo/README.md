# OpenAPI 示例（Dubbo）

基于 Dubbo 的 OpenAPI 文档示例，展示 `cubo-openapi-dubbo-spring-boot-starter` 在 Dubbo 服务场景下生成 API 文档的能力。

## 运行方式

```bash
mvn spring-boot:run
```

## 演示特性

- Dubbo 服务接口的 OpenAPI 文档生成
- Dubbo 泛化调用与文档集成
- 服务接口元数据的自动采集
